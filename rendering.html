📷 Module 08

Rendering Complete Guide

Cycles & EEVEE settings, denoising strategies, output formats, the Compositor, camera setup, and render optimization.

⚡ Quick Render Checklist
  1. Set render engine: Render Properties → Engine (Cycles or EEVEE)
  2. Set resolution: Output Properties → Resolution X/Y (1920×1080 for HD)
  3. Set frame range: Start/End frame for animation
  4. Choose output folder: Output Properties → Output path
  5. Set file format: PNG (lossless), JPEG (small), EXR (compositing)
  6. Enable denoising for Cycles (Render Properties → Denoising)
  7. Check camera framing: NumPad 0 → Camera view
  8. Press F12 to render current frame, Ctrl+F12 for animation
  9. Rendered images auto-save to output path if set
Always set an output path before rendering animation. Otherwise frames are not saved — only displayed in the render window, then lost.

🎛️ The Compositor
Setting Up the Compositor ›
  1. Change an editor to Compositor type
  2. Check Use Nodes checkbox
  3. You'll see Render Layers node → Composite output
  4. Add nodes between them to apply effects
  5. Enable Backdrop to see the result behind the nodes
  6. Press F12 — the Compositor processes after Cycles/EEVEE finishes

Color Grading Workflow ›
  1. Add Color Balance node — LGG (Lift/Gamma/Gain) method
  2. Lift: adjusts shadows (drag slightly blue/teal for cinematic look)
  3. Gamma: adjusts midtones
  4. Gain: adjusts highlights (slightly orange/warm for sunlit feel)
  5. Add Hue Saturation Value — reduce saturation slightly (0.8–0.9) for realism
  6. Add Glare → Fog Glow with small threshold for subtle bloom
  7. Add Lens Distortion with small Dispersion (0.01) for chromatic aberration
  8. Use Viewer node to preview intermediate stages

🚀 Render Optimization

Use GPU Rendering

Preferences → System → Cycles Render Devices → enable your GPU (CUDA for NVIDIA, HIP for AMD, Metal for Apple Silicon). Can be 10–50× faster than CPU.

Denoising = Fewer Samples

With OIDN or OptiX denoiser enabled, 128 samples can look as clean as 2048 samples without denoising. Always use denoising in final renders.

Render Regions

In camera view, press Ctrl+B to drag a render region. Only that area will render — perfect for testing a small part of a complex scene without full renders.

Cryptomatte for Masking

Enable Cryptomatte passes instead of re-rendering with different materials to create masks. Save massive time in compositing — select objects by clicking them in the Compositor.

Render Image Sequences

Always render animations as PNG sequences, not video. If a render crashes at frame 432, you can resume from there. Combine to video in Video Sequence Editor afterward.

Simplify Scene

Render Properties → Simplify → set Max Subdivision to 2 for viewport, 6 for render. Reduces subdivision modifier complexity during interactive work without changing final quality.
