Sculpting Complete Guide

Digital clay for organic shapes, characters, and detailed surfaces. Workflows, all brushes, topology methods, and pro techniques.

🔄 Full Sculpting Workflow
  1. Start with a UV Sphere or high-poly base mesh (Shift+A → UV Sphere)
  2. Object Mode → switch to Sculpt Mode (top-left mode dropdown)
  3. Set Voxel Size in the header (e.g. 0.05) — smaller = more detail
  4. Press Ctrl+R to Voxel Remesh — uniform clean topology
  5. Enable X Mirror symmetry in the header toolbar
  6. Block out major masses with Clay Strips and Grab brush
  7. Remesh again (smaller voxel) when you need more resolution for details
  8. Refine with Smooth (Shift), Flatten, Scrape
  9. For fine detail: switch to Multires modifier approach
  10. Add wrinkles, pores, detail with Crease, Pinch, Draw Sharp
  11. Final polish: Smooth, Flatten, Polish brushes
Performance: Stay in Solid mode while sculpting. Switch to Rendered view only to check materials. Keep Multires viewport level low while working.

⚙️ Topology Methods — Which to Use When
Voxel Remesh — Best for Early Blocking ›

Rebuilds the entire mesh with uniform voxel-based topology. Use between blocking stages.

  • Set Voxel Size in header — smaller number = more polygons
  • Ctrl+R to remesh, or click the Remesh button in header
  • Pro: Clean uniform topology, no poles, fast
  • Con: Destroys UV maps, existing edge loops, and rigging
  • Best for: after rough blocking, before final detailing
Dynamic Topology (Dyntopo) — Add Geometry on the Fly ›

Adds and removes geometry automatically as you sculpt — perfect for free-form blocking.

  • Enable: D key in Sculpt Mode, or toggle in header
  • Detail Type: Relative = follows zoom, Constant = same everywhere, Brush = follows brush size
  • Detail Size: smaller = more geometry
  • Pro: No need to remesh, geometry appears where needed
  • Con: Random topology, no UV maps, slower with very high detail
  • Best for: initial organic blocking
Multires Modifier — Best for Final Detailing ›

Subdivides the mesh while keeping the low-res base editable separately.

  • Add modifier → Multiresolution → click Subdivide to add levels
  • Each level = 4× more polygons
  • Sculpt on high level for fine detail; rig/animate on level 0
  • Apply Base: reshape base mesh while keeping high-res detail
  • Reshape: push high-res sculpt detail onto a new base shape
  • Pro: Keeps UV maps, compatible with rigging
  • Con: Uses more memory, slower for very high levels
  • Best for: characters that need UV maps and animation
Masking & Face Sets — Protect and Isolate ›
  • Mask brush (M): paint regions to protect from sculpting
  • Alt+M clear mask, Ctrl+I invert mask
  • Face Sets: colored regions you can hide/isolate
  • H = hide face set, Alt+H = show all
  • Auto-Masking: enable Topology / Face Sets / Cavity in brush settings
  • Cavity masking: only sculpts on high or low areas of the surface
💡 Sculpting Pro Tips

Build Form First

Work large to small. Big forms → medium details → fine details. Never start with wrinkles before the face shape is correct.

Smooth is Your Friend

Hold Shift anytime to temporarily use the Smooth brush. Use it constantly — perfect sculpting is always adding and smoothing.

Use References

Add → Image → Reference. Place anatomy/concept art in the viewport. Orbit around it constantly to check proportions from all angles.

Matcap Lighting

Switch Solid shading to MatCap (shading dropdown). Clay and wax matcaps reveal surface detail far better than default lighting.

Symmetry Always

Enable X symmetry in the header before you start. Sculpt one side — the other mirrors automatically. Disable symmetry only for asymmetric final details.

Remesh Timing

Remesh when you've blocked the shape and want to add detail. Start with large voxel (0.05–0.1), then get smaller (0.01–0.02) for final details. Don't go too fine too early.
