🌱 Module 01

The Absolute Basics

New to Blender, or coming back after a break? Start here. Everything you need to feel confident before diving into modeling or sculpting.

Installing Blender 4.x

  1. Download from blender.org — always use the latest stable version
  2. Works on Windows, macOS, Linux — portable zip available (no install needed)
  3. On first launch: go to Edit → Preferences to customize
  4. Set keymap: Preferences → Keymap → "Blender" or "Industry Compatible" (Maya-style)
  5. Enable Auto Save: Preferences → Save & Load → every 2 min
  6. Set Undo Steps to 64+: Preferences → System
  7. Enable GPU: Preferences → System → CUDA / OptiX / Metal / HIP

First Things to Configure

Edit → Preferences → ThemeSet visual theme — Blender Dark is default
Output PropertiesResolution 1920×1080, FPS 24
Render Properties → EngineCycles for photorealism, EEVEE for speed
Preferences → Add-onsEnable Node Wrangler, LoopTools, Rigify
Scene Properties → UnitsMetric + unit scale 0.01 for real-world cm
Save your preferences! Preferences → hamburger menu → Save Preferences. Otherwise they reset on next launch.

🎮 Object Modes — Click to Explore
Object Mode (click) Default. Move, rotate, scale whole objects.
Edit Mode (click) Enter mesh editing. Move vertices, edges, faces.
Sculpt Mode (click) Digital clay. Push, pull, smooth organic forms.
Pose Mode (click) Animate armatures. Move bones to pose characters.
Weight Paint (click) Paint how much each bone influences the mesh.
Vertex Paint (click) Paint colors directly on vertices.

👆 Click a mode to learn more

Each mode in Blender gives you a completely different set of tools. Most beginners spend 80% of their time in Object Mode and Edit Mode. Click any mode to see its key shortcuts and use cases.

📐 The 3 Core Transforms — G, R, S
G

Grab / Move

G Z 2 = move 2 units up
G X -1 = move 1 unit left
G Shift+Z = move on X+Y plane only

R

Rotate

R Z 45 = 45° on Z axis
R X 90 = 90° on X axis
R R = trackball (free) rotation

S

Scale

S 2 = double in all axes
S Z 0.5 = half height only
S Shift+Z = scale X+Y only

The Pattern: Press G/R/S → optionally press X/Y/Z to constrain axis → optionally type a number → Enter to confirm. Right-click or Escape to cancel. Ctrl while moving = snap to grid increments.
