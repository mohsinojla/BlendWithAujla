Module 04

Modeling

From primitive shapes to complex meshes — the complete modeling toolkit.

⚡
Before modeling, always apply transforms (Ctrl+A → All) to avoid issues with scale, rotation affecting modifiers and physics.

Core Modeling Workflows

🎯 Box Modeling Beginner

  1. Start with a cube (Shift+A → Mesh → Cube)
  2. Enter Edit Mode (Tab)
  3. Enable X-Ray (Alt+Z) to see through mesh
  4. Select faces and Extrude (E) to build shape
  5. Use Loop Cuts (Ctrl+R) to add edge loops
  6. Bevel edges (Ctrl+B) for smooth corners
  7. Add Subdivision Surface modifier for smooth result

🔄 Retopology Workflow Intermediate

  1. Import/create your high-poly mesh
  2. Enable Snap to Face (Shift+Tab → Face)
  3. Create new mesh object on top of high-poly
  4. Enable "Snap" and "Project Individual Elements" in snap settings
  5. Use LoopTools addon for clean loops (Ctrl+R on curved areas)
  6. Shrinkwrap modifier keeps mesh on surface
  7. Bake normal map from high-poly to low-poly

⚙️ Hard Surface Modeling Pro

  1. Block out major shapes first — don't detail early
  2. Use Boolean modifier for cuts and unions
  3. Add edge loops near booleans for clean shading
  4. Use Bevel Weight on sharp edges (mean crease)
  5. Bevel modifier with Limit Method = Weight
  6. Weighted Normals modifier for correct shading
  7. Mark sharp edges: Ctrl+E → Mark Sharp

🌀 Subdivision Workflow Intermediate

  1. Model with low poly, add Subdivision Surface modifier
  2. Set Viewport = 2, Render = 3 (or higher)
  3. Use edge creases (Shift+E) to sharpen edges
  4. Add support loops near sharp corners
  5. Enable "Optimal Display" to see clean wireframe
  6. Apply modifier when mesh is finalized

📐 Precision Modeling Intermediate

  1. Enable ruler/protractor: Shift+Space → Measure
  2. Type exact values after G/R/S (e.g. G Z 1.5)
  3. Use 3D cursor as pivot point
  4. Set 3D cursor: Shift+RMB or Shift+S
  5. Snap to grid: hold Ctrl while transforming
  6. Use N panel → Item → exact position/scale values
  7. Unit Scale in scene settings for real-world units

🔗 Modifier Stack Best Practices Pro

  1. Order matters: Mirror → Solidify → Bevel → SubDiv
  2. Never apply modifiers until final — keep non-destructive
  3. Use Array + Curve modifier for repeating along path
  4. Boolean: use "Exact" solver for complex shapes
  5. Data Transfer for copying normals between objects
  6. Displace modifier with texture for organic detail
  7. Geometry Nodes for procedural everything

Module 05

Sculpting

Digital clay for organic shapes, characters, and detailed surfaces.

Sculpting Workflow — Start to Finish

  1. Start with a sphere or base mesh (Shift+A → UV Sphere)
  2. Switch to Sculpt Mode from the mode menu
  3. Set Remesh Voxel Size (top header) — lower = more detail
  4. Press Ctrl+R to remesh and get uniform topology
  5. Block out major shapes with Clay Strips brush
  6. Use Grab brush to push/pull large forms
  7. Remesh again when adding detail (smaller voxel size)
  8. Refine with Smooth (Shift), Flatten, Scrape
  9. For fine detail: enable Multires modifier
  10. Add detail with Crease, Pinch, Draw Sharp
  11. Final polish: Smooth, Polish, Flatten

Dynamic Topology vs Multires vs Remesh

Dynamic Topology (Dyntopo) ›

Adds/removes geometry as you sculpt — perfect for early blocking.

  • Enable: D key in Sculpt Mode header
  • Set detail size smaller for more geometry
  • Detail Type: Relative → follows zoom level
  • Constant → same density everywhere
  • Brush → density based on brush size
  • Con: no UV maps, random topology
  • Best for: early blocking, organic forms
Multires Modifier ›

Subdivides mesh while keeping low-res editable — best for final detailing.

  • Add modifier → Multiresolution
  • Subdivide to add levels (each level 4× polygons)
  • Sculpt on high level, render on high, rig on low
  • Apply Base at low level to sculpt big forms
  • Reshape: pushes high-res detail to new low-res shape
  • Best for: characters with animation, final sculpts
Voxel Remesh ›

Rebuilds mesh topology uniformly — use between blocking stages.

  • Set Voxel Size in header (smaller = more polys)
  • Ctrl+R to remesh (or click Remesh button)
  • Smooth Normals option for cleaner result
  • Fix Poles: helps reduce problematic topology
  • Warning: destroys UV maps and existing topology
  • Best for: cleanup after rough blocking
Face Sets & Masking ›

Isolate and protect parts of your sculpt.

  • Ctrl+Alt+LMB — expand face set
  • H — hide face set, Alt+H — show all
  • W in mask mode — mask operations menu
  • Mask by normals: auto-masks flat surfaces
  • Auto-Masking: Topology / Face Sets / Cavity
  • Cavity mask: only sculpts high or low areas

Essential Shader Nodes

Texture Nodes ›
  • Image Texture: Load external image (PNG, JPG, EXR, TIFF)
  • Noise Texture: Procedural noise — great for roughness variation
  • Musgrave: Fractal noise for terrain, rock surfaces
  • Voronoi: Cell pattern — stones, scales, organic
  • Wave: Stripes/bands — wood, marble, fabric
  • Gradient: Linear/radial gradient along object
  • Magic: Colorful psychedelic pattern
  • Checker: Black/white checker pattern
  • Brick: Brick/tile procedural texture
Color & Vector Nodes ›
  • ColorRamp: Map values to colors — control contrast
  • Hue Saturation Value: Adjust colors
  • Mix Color: Blend two colors/textures
  • RGB Curves: Fine-tune color channels
  • Mapping: Control texture UV position/rotation/scale
  • Texture Coordinate: UV / Generated / Object / Camera coord
  • Normal Map: Convert image to normal vector
  • Bump: Convert height map to normal
  • Displacement: Actual geometry displacement
Shader Mix Nodes ›
  • Mix Shader: Blend two shaders with a factor
  • Add Shader: Add two shaders together (emission over material)
  • Emission: Pure emissive surface — glow, screens
  • Transparent BSDF: Pure transparency
  • Glass BSDF: Combined refraction + reflection
  • Diffuse BSDF: Pure diffuse (no specular)
  • Glossy BSDF: Pure reflective/specular
  • Volume Scatter / Absorption: Volumetric fog and glass tint
  • Holdout: Makes object a matte cutout

Module 07

Lighting

Light makes or breaks your render. Master every light type and technique.

💡 Light Types

LightUse Case
PointBulb, omnidirectional. Has radius for soft shadows.
SunParallel rays, infinite distance. Outdoor scenes.
SpotCone of light. Flashlight, stage, car headlight.
AreaRectangular/disk soft light. Studio, windows.
Tip: Area lights with large size give beautiful soft shadows. Set Shape to Disk for round or Rectangle for window light.

🌅 Three-Point Lighting Setup

  1. Key Light: Main light, 45° to side and above subject. Strongest.
  2. Fill Light: Opposite side, 50-75% strength of key. Fills shadows.
  3. Rim/Back Light: Behind subject, creates separation from background.
  4. Optionally add bounce card: a plane with white emission material
  5. Use HDRI for natural ambient fill (World settings → Environment Texture)
Ratio: Key : Fill : Rim = 1 : 0.5 : 0.25 for natural look. Increase contrast for dramatic effect.

🌍 HDRI Lighting

  1. Go to World Properties (globe icon)
  2. Click "Use Nodes" → Surface → Background
  3. Add Environment Texture node
  4. Load .hdr or .exr file (hdri-haven.com / Poly Haven for free HDRIs)
  5. Use Mapping node to rotate HDRI
  6. Adjust Strength for exposure control
  7. For Cycles: enable "Multiple Importance Sampling" on world
Pro: Use a Lightpath node to show a different background to camera vs reflections. Clean background, realistic reflections.

⚙️ Cycles vs EEVEE Lighting

Cycles (Path Tracing)
  • Physically accurate, global illumination
  • Slower — use GPU (CUDA/OptiX/Metal/HIP)
  • Great for still renders, product viz, films
  • Sample count controls noise vs quality
  • Enable Denoising (AI denoiser in render settings)
EEVEE Next (Blender 4.x)
  • Real-time rasterization, extremely fast
  • Enable Screen Space Reflections for reflections
  • Enable Ambient Occlusion in render settings
  • Bloom → Post Processing
  • Shadow settings: increase Resolution for sharp shadows
  • EEVEE Next (4.2+) — much improved ray tracing options

🎨 Light Color Tips

  • Warm key light (slightly orange) + cool fill (slightly blue) = natural contrast
  • Complementary colors in key/fill create cinematic look
  • Use Kelvin temperature: 2700K=warm bulb, 5500K=daylight, 7000K=cloudy/blue
  • Never use pure white light in realism — slight warmth/coolness always
  • Emission materials as lights: set material to Emission, use as lamp
  • Light Linking (Blender 4.x): control which objects each light affects

🌫️ Volumetrics & Atmosphere

  1. Add a cube around scene: Material → Volume → Volume Scatter
  2. Low density (0.01–0.05) for subtle atmosphere/haze
  3. Spot light through volume = god rays
  4. World volume for global fog: World → Volume → Volume Scatter
  5. In EEVEE: enable Volumetrics in Render Properties
  6. In Cycles: just add volume material — renders automatically
Module 08

Animation

Keyframes, curves, rigging, and making things move beautifully.

Keyframing Fundamentals

  1. Set playhead to frame 1 in Timeline
  2. Select object, press I → choose what to keyframe (Location, Rotation, Scale)
  3. Move to frame 24, transform object
  4. Press I again to set second keyframe
  5. Press Space to play — object animates between keyframes
  6. Open Graph Editor to adjust animation curves
  7. Press T in Graph Editor to change interpolation
Auto Keying: Enable the record button (circle) in the Timeline header. Every transform change automatically creates keyframes.

Rigging Basics

Create a Simple Rig ›
  1. Add Armature: Shift+A → Armature
  2. Enter Edit Mode on armature (Tab)
  3. Extrude bones: E to add child bones
  4. Name bones in Properties → Bone Properties
  5. Exit armature edit mode, select mesh then armature
  6. Parent: Ctrl+P → With Automatic Weights
  7. Select armature, enter Pose Mode (Ctrl+Tab)
  8. Now move bones to pose the mesh
Constraints — The Power of Rigging ›
  • IK (Inverse Kinematics): Move end bone, chain follows. Perfect for arms/legs.
  • Copy Rotation: Bone mirrors rotation of another.
  • Track To: Always point at a target object.
  • Floor: Prevent bone going below a plane.
  • Limit Rotation: Clamp rotation range for joints.
  • Child Of: Dynamic parenting between objects.
  • Add via: Bone Properties → Bone Constraints tab (chain icon)
Shape Keys ›
  • Object Properties → Shape Keys
  • Add "Basis" key first — this is rest state
  • Add new key, enter Edit Mode, deform mesh
  • Exit — that deformation is now the shape key
  • Keyframe the Value (0–1) slider for facial animation
  • Driver: Link value to bone rotation for automatic triggering
  • Great for: facial expressions, corrective shapes, morphs

NLA Editor — Non-Linear Animation

  1. Animate a looping walk cycle on frames 1-24
  2. Open NLA Editor
  3. Click the push-down button (star icon) on the action
  4. Action becomes an NLA strip
  5. Drag strip length to repeat the loop
  6. Blend multiple actions together with Blend In/Out
  7. Scale strip to slow down or speed up animation
Use case: Animate walk, run, idle cycles separately. Blend in NLA for game-ready character animation or complex scene choreography.

Animation Tips for Realism

01

Squash & Stretch

Objects squash on impact and stretch during fast movement. Even subtle squash/stretch on a bouncing ball makes it feel alive.

02

Anticipation

Before a big move, briefly move in the opposite direction. A character crouch before jumping. Pulls viewers attention.

03

Follow Through & Overlap

Secondary elements (hair, clothes, tail) should continue moving briefly after the main body stops — and not all at the same rate.

📤 Output Settings

  1. Output Properties → Resolution: 1920×1080 (or your target)
  2. Frame Rate: 24fps (film), 30fps (video), 60fps (games/smooth)
  3. Output Path: Set a folder to save frames to
  4. File Format: PNG for still, OpenEXR for compositing
  5. For animation: render as PNG sequence, not video directly
  6. Combine PNG sequence with Video Sequencer or FFmpeg after
  7. Color Management: Filmic (default) for natural; AgX (4.x) for modern look
  8. Exposure/Gamma: adjust in Color Management section
Always render PNG sequence! If Blender crashes on frame 847, you can resume from there. Rendering directly to video = start over.

🚀 Render Speed Optimization

  • Enable GPU in Preferences → System → CUDA/OptiX/HIP/Metal
  • Use Denoising aggressively — lower samples + denoise = faster
  • Reduce Light Path bounces (diffuse to 2, volume to 0)
  • Simplify: Render Properties → Simplify → Reduce SubDiv for render
  • Use Render Regions (Ctrl+B in camera view) for test renders
  • Viewport: lower viewport samples (16-32) while working
  • Persistent Data in render settings = huge animation speedup
  • Use Collections to hide/show objects — exclude from render
  • Bake textures for complex procedural shaders

🎭 Compositor

  1. Render Properties → check "Use Compositing"
  2. Open Compositor editor (or add it as new area)
  3. Enable "Use Nodes" in header
  4. Render Layers → Composite = basic pass-through
  5. Add effects between Render Layers and Composite
  6. Glare node = bloom/streaks on bright areas
  7. Color Balance = professional color grading
  8. Vignette: use Ellipse Mask → Invert → Multiply
  9. Lens Distortion for chromatic aberration
  10. Use View Layer passes: Z-depth, Normal, AO for more control

Module 10

Pro Tips & Hidden Gems

Things that took years to discover — now you know them from day one.

01

F9 — The Most Underused Key

After any operation, press F9 to get a popup to adjust the last action's settings. Added 16 loop cuts but want 8? F9 and change it. Works for almost everything.

02

Right-Click Menus Have Everything

Right-click in the viewport, on properties, on nodes — context menus appear. Many powerful options like "Set Origin," "Mark Sharp," "Subdivide" are only in right-click menus.

03

Render from Command Line

Start background renders with: blender -b file.blend -f 1 for frame 1. -a for full animation. Run overnight while using PC normally.

04

Link vs Append Libraries

File → Link brings in assets from other .blend files as read-only references. File → Append makes a local copy. Link = always updated, great for team workflows and master material libraries.

05

Proportional Editing is Magic

Press O in Edit Mode. Move one vertex and surrounding vertices follow smoothly. Scroll to adjust falloff radius. Use Connected-only mode for organic free-form modeling.

06

Quick Favorites (Q Menu)

Right-click any tool or menu item → Add to Quick Favorites. Then press Q for instant access to your most-used tools. Build a custom toolkit per project.

07

Drivers = Automatic Everything

Right-click any property → Add Driver. Link material color to an object's X position, control rig shape keys with bone rotation. Drivers turn manual animation into automatic relationships.

08

Asset Library for Reuse

Edit → Preferences → File Paths → Asset Libraries. Mark objects/materials/poses as assets. Drag them into any project. Build your own library of materials, objects, node groups.

09

Overlay Toggle per Object

In Properties → Object Properties → Visibility → hide from render, viewport, or both independently. Keep guides and reference objects visible in viewport but invisible in render.

10

Hold Alt to Edit All Selected

Select multiple objects, hold Alt when changing a property — changes apply to all selected. Works for material settings, modifier values, and many properties.

11

Geometry Nodes — Procedural Power

Add Geometry Nodes modifier. Build procedural geometry with nodes — scatter objects on surfaces, create patterns, generate complex arrays. No manual work, fully parametric and non-destructive.

12

Python Console for Bulk Operations

Open Python Console, select all objects of a type, run a script to change all their materials, rename them, or apply modifiers. The Info Editor shows the Python code for every operation you do manually.

13

Custom Properties for Rigs

Object Properties → Custom Properties → Add. These show up as sliders you can keyframe. Perfect for rig control parameters, IK/FK blend sliders, and studio production controls.

14

Backface Culling Trick

In solid viewport: Overlays → enable Backface Culling to immediately see inside-out normals. Any dark patches are reversed normals. Fix with Shift+N (Recalculate Normals).

15

Render with Multiple Camera Views

Add multiple cameras. In Outliner, right-click a camera → Set Active Camera. Or use Camera selector in Output Properties. Script batch renders from each camera angle automatically.

16

Snap Increment vs Absolute Grid

Hold Ctrl while transforming to snap to grid. In header, change Snap to "Increment" for relative or "Grid" for absolute world grid. Critical for architectural/technical work.

17

Use Reference Images (Empty)

Add → Image → Reference. Positions a reference image in 3D space. Set to "In Front" to always see it. Perfect for matching real-world shapes, concept art, or blueprints.

18

Collections = Organization Power

Use Collections (M key) to group objects logically. You can link entire collections between files, hide/show groups with one click, exclude from render per View Layer. Game changer for complex scenes.

19

Modal Operators — Type While Active

After pressing G, R, or S — type an axis (X/Y/Z) then a number (45, 2.5, etc). You can see your exact value and confirm with Enter. G Z -2 moves exactly -2 units down.

20

The N Panel Has Scene Data

Press N in any editor to open the sidebar. In 3D viewport: Item tab shows exact transforms, View tab has camera settings, Tool tab has active tool options. This is where precision lives.

21

Cavity in Viewport Shading

In Solid mode, click the Viewport Shading dropdown → enable Cavity. This adds ambient occlusion to solid mode, making it much easier to see the mesh detail while modeling and sculpting.

22

Matcaps for Sculpting

In Solid mode shading dropdown, switch from Material to MatCap. These are pre-baked shaders great for seeing surface detail while sculpting. Clay, wax, and metal matcaps are built-in.

23

Texture Paint Directly on Mesh

Switch to Texture Paint mode. Create a new image in Image Editor. Add Image Texture node in material pointing to same image. Paint directly on mesh in 3D viewport.

24

Render Passes for Compositing Control

View Layer Properties → Passes. Enable AO, Shadow, Diffuse, Specular, Z-depth. Each renders as separate layer. In compositor, mix them independently for maximum control over final look.

Common Blender Problems & Fixes

Object looks dark/black in render ›
  • Check if normals are flipped: Overlay → Face Orientation (blue=correct, red=flipped). Fix: Shift+N
  • No lights in scene — add a Sun or Area light
  • Material is missing or has Emission=0 and Roughness=1 with no light
  • Object is inside another object that blocks light
Render has lots of noise/fireflies ›
  • Increase sample count
  • Enable Denoising in Render Properties
  • Clamp Indirect lighting (Render → Light Paths → Clamping → Indirect = 10)
  • Fireflies often come from very bright small lights — reduce light energy or increase size
  • Caustics cause fireflies — disable in Light Paths settings
Object disappears in viewport ›
  • Might be hidden: press Alt+H to unhide all
  • Collection is hidden — check Outliner, look for eye icon
  • Clip End too short: Camera properties → Clip End → increase value
  • Local View active: press / to exit local view
  • Object is on a disabled View Layer
Modifier not working as expected ›
  • Apply Scale first: Ctrl+A → Scale (especially for Mirror, Cloth, Physics)
  • Modifier order matters — drag modifiers to reorder
  • Mirror: make sure Mirror Object is set or origin is in correct place
  • Boolean: use "Exact" solver for complex meshes
  • SubDiv: mesh has n-gons that cause shading artifacts — triangulate or clean topology
Animation stutters or looks wrong ›
  • Playback not real-time: Timeline → Playback → Sync → Frame Dropping or AV-sync
  • Check interpolation in Graph Editor — Linear vs Bezier makes huge difference
  • Missing keyframes: check Auto Keying is off when not wanted
  • Physics simulation needs to be baked: Properties → Cache → Bake
Blender is slow / running out of memory ›
  • Enable GPU rendering: Preferences → System → CUDA/OptiX/HIP/Metal
  • Reduce poly count: use Decimate modifier or lower SubDiv levels
  • Linked duplicates instead of real copies: Alt+D instead of Shift+D
  • Purge unused data: File → Clean Up → Purge All
  • Render in tiles if running out of VRAM (Render → Performance → Tiles)
  • Use Simplify in render settings to limit subdivision for preview
