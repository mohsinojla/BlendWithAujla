Lighting Complete Guide

Light types, 3-point lighting setup, HDRI environment lighting, Cycles vs EEVEE differences, and volumetric effects.

🔦 Light Types
TypeDescriptionBest For
PointOmni-directional, from single pointBulbs, candles, fire
SunParallel rays, only angle mattersOutdoor scenes, shadows
SpotCone-shaped, adjustable angleStage lights, headlamps
AreaRectangle/disc, soft shadowsStudio lighting, fill lights
Area lights give the softest, most realistic shadows. For product shots and characters, area lights almost always look better than point lights.

① Key Light

  • 45° side + 45° above
  • Brightest of the three
  • Sets main direction/mood
  • Area light recommended
  • Warm tint (3200–4500K)

② Fill Light

  • Opposite side of key
  • 30–50% of key power
  • Softens harsh shadows
  • Cooler tint (6500K)
  • Shadows optional

③ Rim Light

  • Behind the subject
  • Creates depth/separation
  • Similar power to key
  • Can be colorful
  • Spot or area works

🌍 HDRI Environment Lighting
Setting Up HDRI
  1. Switch to World Properties (globe icon)
  2. Click Use Nodes if not already enabled
  3. Click the dot beside Color → Environment Texture
  4. Click Open → select your .hdr or .exr file
  5. In viewport, press Z → Rendered to preview
  6. Add Texture Coordinate + Mapping nodes to rotate HDRI
  7. Adjust World Strength to increase/decrease influence
HDRI simultaneously provides lighting AND reflections. One HDRI can replace an entire light rig for product shots. Use Polyhaven.com for free 4K–16K HDRIs.
HDRI Power Tips
Background VisibleWorld → Surface → Light Path → Is Camera Ray

HDRIs are panoramic equirectangular images (360°×180°) that encode real-world high dynamic range light data — they capture everything from the sun to shadows.
⚡ Cycles vs EEVEE Lighting
Cycles — Path Tracing (Physically Accurate) ›

Simulates real light transport — rays bounce around the scene. Slow but physically correct.

  • Caustics: light focusing through glass (enable in Render → Caustics)
  • Indirect lighting: automatic — light bounces off surfaces and illuminates others
  • Light Paths: control bounce count (8 default, lower = faster)
  • Denoising: OptiX (NVIDIA GPU) or OpenImageDenoise (CPU)
  • Samples: 64–256 for final render
  • Best for: photorealism, glass, SSS, hair, complex lighting
EEVEE — Real-Time Rasterizer (Fast) ›

Renders in real-time using GPU rasterization. Fast but requires manual setup for advanced effects.

  • Ambient Occlusion: enable in Render Properties for contact shadows
  • Screen Space Reflections: enable for reflections (only what's on screen)
  • Shadows: set Shadow Map resolution per light for quality
  • Bloom: glow effect on bright/emissive objects
  • Volumetrics: enable for fog/atmospheric effects
  • Best for: animation previews, stylized renders, real-time
Volumetric Lighting — Fog, God Rays, Atmosphere ›
  • In World Properties → enable Volumetric (EEVEE)
  • For Cycles: add a cube object, apply Volume Scatter material
  • Density controls thickness; Anisotropy controls light direction
  • Spot lights through volumetrics create "god rays"
  • In EEVEE → Volumetrics → smaller Tile Size = higher quality
  • Use Volume Absorption for colored fog/smoke
Light Linking (Blender 4.x) ›
  • Blender 4.x supports Light Linking natively
  • Specify exactly which objects each light illuminates
  • Object Properties → Visibility → Light Linking panel
  • Revolutionary for VFX and character lighting without affecting environment
  • Create per-object shadow catchers and light exclusion zones
✨ Lighting Pro Tips

Color Temperature

Warm key + cool fill = natural outdoor look. Cool key + warm fill = sci-fi/surreal. Matching temperatures looks flat — contrast creates depth.

Light Exclusion

Object Properties → Visibility → uncheck collections a light affects. Use this so a light only illuminates the character, not the background.

Shadow Bias

See "shadow acne" (dark spots)? Increase Shadow Bias in light settings. Too high = floating shadows. Find the sweet spot for your scene scale.

Fake Bounce Light

In EEVEE, indirect bounce is limited. Add invisible emission planes near floor/walls to simulate bounce light. Set them to not cast shadows.

Study Photography

The fastest way to improve 3D lighting is to study real photography. BTS photos from film sets are gold. Learn the vocabulary: rembrandt, butterfly, split lighting.

Use MatCap to Check

Switch to Solid mode → Matcap to see your mesh's form clearly before committing to lights. A good form should read well even without complex lighting.
