🔧 Module 03

Modeling Complete Guide

From primitive shapes to complex meshes. Workflows, tools, modifier reference, and best practices.

⚡
Always Apply Transforms (Ctrl+A → All) before adding modifiers or physics. Unapplied scale causes countless strange bugs.
🎯 Core Modeling Workflows

🎯 Box Modeling Beginner

  1. Start with a cube — Shift+A → Mesh → Cube
  2. Enter Edit Mode (Tab), enable X-Ray (Alt+Z)
  3. Select faces and Extrude (E) to build shape
  4. Add Loop Cuts (Ctrl+R) for more detail
  5. Bevel edges (Ctrl+B) for smooth corners
  6. Add Subdivision Surface modifier for smooth final mesh

🌀 Subdivision Workflow Intermediate

  1. Model with low-poly — add Subdivision Surface modifier
  2. Viewport Levels = 2, Render Levels = 3
  3. Use edge creases (Shift+E) to sharpen specific edges
  4. Add support loops near corners to tighten edges
  5. Enable "Optimal Display" to see clean wireframe
  6. Apply modifier only when the mesh is completely finalized

⚙️ Hard Surface Pro

  1. Block out all major shapes first — don't detail early
  2. Use Boolean modifier for cuts, unions, differences
  3. Add edge loops near booleans for clean shading
  4. Bevel modifier with Limit Method = Weight
  5. Set Bevel Weight on sharp edges with Ctrl+E → Bevel Weight
  6. Add Weighted Normals modifier at the end of stack
  7. Mark sharp edges: Ctrl+E → Mark Sharp

🔄 Retopology Intermediate

  1. Have your high-poly sculpt or imported mesh ready
  2. Add new empty mesh object on top of high-poly
  3. Enable Snap to Face (Shift+Tab snap pie → Face)
  4. Enable "Project Individual Elements" in snap options
  5. Draw quads that follow the surface topology
  6. Shrinkwrap modifier keeps new mesh welded to surface
  7. Bake normals from high-poly to retopo mesh for texture

📐 Precision Modeling Intermediate

  1. Set Scene Units: Scene Properties → Units → Metric
  2. Type exact values after G/R/S: G Z 1.5 = move 1.5m up
  3. Set 3D cursor: Shift+S → Cursor to selected/grid
  4. Set pivot to 3D Cursor, model radially
  5. N panel → Item tab → type exact location/scale values
  6. Hold Ctrl while moving to snap to grid
  7. Ruler tool: Shift+Space → Measure

🔗 Modifier Stack Order Pro

  1. Mirror — always first for symmetrical objects
  2. Array — repeat before other deformations
  3. Solidify — add thickness early
  4. Bevel — round edges before subdividing
  5. Subdivision Surface — smooth at end
  6. Displace / Shrinkwrap — deform after shape is set
  7. Weighted Normals — always last in hard surface
Never apply modifiers until the model is truly final. Keep the stack non-destructive as long as possible.

💡 Modeling Pro Tips

Mirror First

Add Mirror modifier before doing any real modeling. Model only one half. Apply only at the very end. Always work in symmetry.

Boolean Cleanup

After a boolean cut, add edge loops near the cut edges. This prevents SubDiv from pinching. Use "Exact" solver for complex intersections.

Topology Density

Use denser topology only where detail exists. Flat areas can have very few polygons. Save polygons for curved and detailed regions.

Apply Scale Always

Ctrl+A → Scale before adding any modifier. Unapplied scale breaks Mirror, Cloth, Boolean, Array, and physics simulations.

Alt+D for Duplicates

Use Alt+D (linked duplicate) instead of Shift+D for repeated objects. Edit the mesh in one and all instances update.

Geometry Nodes

For scatter, arrays, and procedural patterns — use Geometry Nodes instead of manual placement. Fully parametric, instantly adjustable.
