🎬 Module 07

Animation Complete Guide

Keyframing, the Graph Editor, rigging with Armatures, Shape Keys, NLA Editor, and physics simulations.

🎯 Keyframing Basics
  1. Go to frame 1 on the timeline (Shift+← or type frame number)
  2. Select object, position/rotate/scale it as desired
  3. Press I to insert keyframe → choose Location, Rotation, Scale, or LocRotScale
  4. Move to another frame, change the object's transform
  5. Press I again to keyframe at this new state
  6. Press Space to play — Blender interpolates between keyframes
  7. Open Graph Editor to control interpolation curves
  8. Right-click keyframe → Interpolation Mode to change easing
Auto Keying: Enable the red circle button on the timeline to auto-insert keyframes whenever you transform an object. Great for rough animation passes.

🦴 Rigging with Armatures
Creating an Armature ›
  1. Shift+A → Armature → Single Bone
  2. Switch to Edit Mode on the armature (Tab)
  3. Select bone tip → E to extrude new bones
  4. Name each bone clearly: "spine", "upper_arm_L", "thigh_R", etc.
  5. Use X-Axis Mirror in Armature properties to create symmetric bones
  6. Parent bones by selecting child → Shift-select parent → Ctrl+P → Keep Offset
Skinning — Binding Mesh to Armature ›
  1. Select mesh first, then Shift+click armature
  2. Ctrl+P → With Automatic Weights
  3. Blender calculates vertex weights automatically
  4. Test by going to Pose Mode on the armature and moving bones
  5. Fix bad deformation: select mesh → Weight Paint Mode
  6. Paint red = full influence, blue = no influence for each bone
  7. Use Smooth and Blur brushes to blend weight transitions
Inverse Kinematics (IK) ›
  • In Pose Mode: select a bone → Bone Constraints → Inverse Kinematics
  • Set Chain Length = 2 for elbow/knee IK chains
  • Create an IK target bone (controller) and point the IK constraint at it
  • IK makes hands/feet plant while the upper body moves
  • Add Pole Target for elbow/knee directional control (prevents flipping)
  • FK (Forward Kinematics) = rotate each bone individually; IK = move end effector
Shape Keys — Facial Animation & Morphs ›
  • Select mesh → Object Data Properties → Shape Keys panel
  • Click + to add Basis (rest pose) key first
  • Add another key, then go to Edit Mode and reshape the mesh
  • Each shape key stores a sculpted deformation (smile, blink, phoneme)
  • Value 0 = no effect; Value 1 = full deformation
  • Keyframe the Value slider to animate morphs over time
  • Driver shapes by bone rotation for automatic facial rig expressions
🎞️ NLA Editor — Non-Linear Animation
NLA Workflow
  1. Animate an action normally in the timeline (e.g. a walk cycle frames 1–24)
  2. Open NLA Editor from the editor type dropdown
  3. Click the Push Down button (down arrow) to push current action into NLA
  4. The action becomes an NLA strip you can loop, scale, blend
  5. Right-click strip → Repeat to loop the walk cycle
  6. Create more actions (run, jump, idle) and push them down
  7. Blend between strips using the Blend In/Out handles
  8. Extrapolation: hold mode or nothing after strip ends
NLA Strip Controls
NStrip properties panel (scale, repeat, offset)
GMove strip in time
SScale strip (changes speed)
Blend ModeReplace, Add, Multiply strips together
InfluenceHow much the strip contributes (0–1)
MuteToggle strip on/off for testing
NLA is powerful for game-ready animations — author walk, run, idle, jump as separate actions, then combine them in the NLA. Export each action as its own animation to a game engine.
🌊 Physics Simulations

Rigid Body

Objects that fall, collide, and bounce with physical mass.

  • Physics Properties → Rigid Body → Active
  • Floor → Rigid Body → Passive
  • Set Shape: Convex Hull or Mesh for accuracy
  • Space to simulate in viewport
  • Bake → Bake to save simulation as keyframes

Cloth Simulation

Realistic fabric draping, flags, and soft bodies.

  • Physics Properties → Cloth
  • Presets: Cotton, Silk, Denim, Leather
  • Pin Groups: select vertices → Group → pin in cloth settings
  • Self-Collision for detailed folds
  • Cache → Bake to lock simulation

Particle Systems

Hair, fur, grass, and particle effects.

  • Particles Properties → + New
  • Type: Emitter (flying) or Hair (static)
  • Render As: Object to instance meshes
  • Use Geometry Nodes Hair in Blender 4.x
  • Children: Interpolated for dense realistic hair
✨ Animation Pro Tips

12 Principles of Animation

Squash & stretch, anticipation, follow-through, arcs, ease in/out, secondary action — these Disney principles apply to all 3D animation. Study them.

Pose to Pose First

Create the key extreme poses first (pose-to-pose method), then fill in breakdown poses. Don't animate every frame linearly from start to finish.

Arcs

Everything in nature moves in arcs, never straight lines. Check the motion path of hands and heads (Object Properties → Motion Paths) and curve any straight trajectories.

Overlap & Follow Through

Hair, clothing, and secondary elements should continue moving after the main body stops. Offset their keyframes by 2–4 frames and add slight overshooting.

24fps for Film

Set FPS in Output Properties. Film = 24fps, TV = 25fps (PAL) or 30fps (NTSC), Games = 60fps. Wrong FPS will make your animation feel wrong when played back.

Stepped Preview

In Graph Editor → View → Use Zero Tangent Handles for stepped/blocking preview. See your key poses without interpolation before committing to splines.
