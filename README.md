# ⬡ Blend with Aujla

**A complete, interactive Blender 4.x learning website** — built for beginners and pros alike. No frameworks, no install, just open and learn.

🌐 **Live Site:** [https://mohsinojla.github.io/BlendWithAujla](https://mohsinojla.github.io/BlendWithAujla)

---

## ✨ Features

- 🎨 **Dark / Light theme** — persisted across sessions
- ⌨️ **Interactive keyboard** — hover over keys to see what they do
- 🔍 **Live search** — find any shortcut or topic instantly from the navbar
- 📱 **Fully responsive** — works on desktop, tablet, and mobile
- 🧩 **Interactive visuals** on every page — learn by doing, not just reading
- 🚀 **Scroll-reveal animations** — smooth, distraction-free transitions
- 📊 **Animated counters** — stats that come alive as you scroll

---

## 📚 Modules

| Page | What You'll Learn |
|------|-------------------|
| 🏠 **Home** (`index.html`) | Overview, stats, interactive keyboard shortcut preview |
| 🧱 **Basics** (`basics.html`) | UI map, viewport navigation, object/edit modes |
| 🔷 **Modeling** (`modeling.html`) | Edit mode tools, modifiers, topology tips |
| 🎨 **Sculpting** (`sculpting.html`) | Brush picker, sculpt workflow, remeshing |
| 🌈 **Materials** (`materials.html`) | Shader nodes, PBR texturing, interactive node flow |
| 💡 **Lighting** (`lighting.html`) | 3-point lighting diagram, light types, HDRI |
| 🎬 **Animation** (`animation.html`) | Interactive timeline, keyframes, Graph Editor |
| 📷 **Rendering** (`rendering.html`) | Cycles vs EEVEE, quality presets, render settings |
| ⌨️ **Shortcuts** (`shortcuts.html`) | Full shortcut reference by category |
| 💡 **Tips** (`tips.html`) | Pro tips, common fixes, BlenderKit & Sketchfab guide |

---

## 🛠️ Technologies

- **HTML5 / CSS3 / Vanilla JS** — zero dependencies
- CSS custom properties for theming
- `IntersectionObserver` for scroll-reveal and counter animations
- `localStorage` for theme persistence
- Pure CSS animations (`@keyframes`)

---

## 🚀 Getting Started

Just open `index.html` in any modern browser — no server needed.

```bash
git clone https://github.com/mohsinojla/BlendWithAujla.git
cd BlendWithAujla
# open index.html in your browser
```
