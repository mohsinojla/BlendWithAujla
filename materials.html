🎨 Module 05

Materials & Shading

PBR physically-based materials, the Shader Editor, Principled BSDF deep-dive, procedural textures, and Node Wrangler workflow.

🧱 PBR Workflow — Step by Step
  1. Select object → go to Properties → Material tab (sphere icon)
  2. Click New to create a material slot
  3. Switch editor to Shader Editor (top bar → Editor Type)
  4. You'll see Principled BSDF → Material Output by default
  5. Enable Node Wrangler add-on (Edit → Preferences → Add-ons)
  6. Select Principled BSDF, press Ctrl+Shift+T → select texture files
  7. Node Wrangler auto-creates Image Texture nodes and connects them
  8. Set Base Color image to sRGB, all others to Non-Color
  9. Add UV Map node if object needs explicit UV control
  10. Preview with Z → Material Preview or Rendered mode
Color Space matters: Base Color / Emission → sRGB. Roughness, Metallic, Normal, AO maps → Non-Color (Linear). Wrong color space washes out or darkens your maps.

🌊 Common Shader Setups
Glass / Transparent Material ›
  • Principled BSDF → set Transmission = 1.0, Roughness = 0.0, IOR = 1.45
  • In Material Properties → Blend Mode: Alpha Hashed (EEVEE) or use Cycles
  • Roughness > 0 makes frosted glass
  • Add Volume Absorption node for colored glass depth effect
  • Cycles tip: Increase Light Path → Transmission bounces to 8+ for accurate glass
Procedural Metal — No Textures ›
  • Metallic = 1.0, Roughness driven by noise for variation
  • Add: Noise Texture → ColorRamp (remap to 0.1–0.4 range) → Roughness
  • Add: Bump node from Noise for surface micro-detail
  • Anisotropic 0.3–0.6 for brushed metal look
  • Anisotropic Rotation driven by a UV Map or object coordinates
Skin / Subsurface Scattering ›
  • Base Color = skin texture (sRGB)
  • Subsurface Weight: 0.1–0.3; Scale: ~0.01 for face-sized objects
  • Subsurface Radius: [1.0, 0.2, 0.1] (R scatters furthest)
  • Roughness: 0.4–0.6 (skin is not perfectly rough or smooth)
  • Specular IOR Level: 0.3–0.5 for realistic skin sheen
  • Use Cycles for accurate SSS — EEVEE SSS is approximated
Emission / Glowing Material ›
  • Set Emission Color to desired glow color
  • Emission Strength: 1–50 depending on desired bloom intensity
  • In Render Properties → enable Bloom (EEVEE) for soft glow
  • Mix Shader: combine Emission + Principled BSDF for glowing-but-also-reflective surfaces
  • Animate Emission Strength with keyframes for flickering effects
Displacement — Real Surface Detail ›
  • In Material → Settings → Displacement: Displacement Only (or Both)
  • Add: Displacement node → connect Height map → Displacement input of Material Output
  • Cycles only: enable Experimental render features for adaptive subdivision
  • Add Subdivision modifier set to Adaptive for real displaced geo
  • Midlevel = 0.5 (neutral), Scale = controls depth
  • Bump maps fake displacement (cheaper); Displacement creates real geometry

💡 Materials Pro Tips

Non-Color is Critical

Every texture except Base Color and Emission must be set to Non-Color. Roughness in sRGB adds a gamma curve that makes rough surfaces look wrong.

Node Wrangler Preview

Hold Ctrl+Shift and click any node to preview just that node's output on the mesh. Invaluable for debugging complex node trees.

Reuse Materials

Click the material name and prepend with a dot (e.g. .Gold) to make it a "fake user" — it persists even if no object uses it. Share materials across files with Append.

Multiple Material Slots

In Edit Mode, select faces, assign different material slots. Good for car bodies (body paint + glass + chrome all on one mesh).

ColorRamp Power

ColorRamp is the most versatile node. Use it to clamp, posterize, invert, or create custom gradients from any grayscale input. Learn it deeply.

EEVEE vs Cycles

EEVEE is real-time and fast — great for previews and stylized renders. Cycles is path-traced and physically accurate. Some nodes (SSS, true refraction) only work well in Cycles.
